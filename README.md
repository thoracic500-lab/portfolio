# Choto Afa | Umme Saima Jerin

Open `index.html` to use the portfolio. The HTML, styling, scripts, icons, artwork, two project demos and downloadable portfolio CV are local files. No installation or build step is required. The former About, Projects, Services and Contact page URLs lead to their corresponding sections.

## Personalize the portfolio

- Set `email` in `assets/js/profile.js` to the public address for inquiries. The contact form validates the inputs and opens a draft in the visitor’s email application. The visitor reviews and sends the message there. With the address blank, the draft requires a recipient. The copy button uses the same address.
- Set each value in `social` to the full HTTPS profile URL, in the order WhatsApp, Facebook, GitHub, X and Messenger. For WhatsApp use a `https://wa.me/` link with the country code and number. Until a destination is configured, selecting its icon shows its availability message.
- Enter the actual GitHub URLs for `repositories.chromatic` or `repositories.fold` to show the repository buttons in the project dialogs. Both demos are included and can be opened offline.
- Replace `assets/files/umme-saima-jerin-cv.pdf` with your own CV when ready. The included one-page portfolio profile covers the work displayed here.
- Edit the biography, FAQ and card labels in `index.html`. Project dialog descriptions are in `assets/js/main.js`.

## Interaction and accessibility

The site includes keyboard navigation, focus indicators, a skip link, native project dialogs, reduced-motion support, and a radial social menu that closes with Escape. Theme and accent preferences persist when browser storage is available. Clipboard features work best on localhost or HTTPS.

The original sculpture is bundled as a WebP. The five social marks are distributed with the Bootstrap Icons license in `assets/images/`.
